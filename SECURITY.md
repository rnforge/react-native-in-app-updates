# Security Policy

## Supported Versions

Only the latest published version of `@rnforge/react-native-in-app-updates` is supported.

## Reporting a Vulnerability

Please report security vulnerabilities privately to **security@rnforge.dev**.

Do not open public issues for security bugs.

## General Support

For package usage questions, docs issues, or public support, please open a GitHub issue.

If GitHub issues are not appropriate for your question, email **support@rnforge.dev**.
